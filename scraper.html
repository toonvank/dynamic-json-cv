Sync Cookies & Session

Your VDAB session requires valid authentication cookies to query search and detail endpoints.

🦊 Firefox (Recommended / Auto-Sync):

If you use Firefox, no extension or copy-pasting is needed! The local server can directly read the active cookies database:

  1. Open Firefox and log in to vdab.be.
  2. Click the **"Auto-Sync Firefox Cookies"** button on this page.
  3. The server will automatically fetch, import, and save your current session cookies.

🌐 Other Browsers (Manual Import):

  1. Log in to vdab.be in your browser.
  2. Open Developer Tools (press F12 or right-click -> **Inspect**).
  3. Navigate to the **Network** tab, reload the page, and select any request to vdab.be (e.g. zoek or page load).
  4. Under **Request Headers**, copy the full value of the Cookie header.
  5. Paste it into the **Cookies & Correlation Headers** input field on this dashboard and click **Save Config**.
